# 本机模型额度同步（Grok + Gemini）

一个扩展管理两个来源，沿用已安装 Grok 扩展的目录、固定身份和已有 Grok 绑定。目录仍叫 grok-browser-extension 是为了兼容已有安装，不需要再加载第二个扩展。

## 更新已有扩展

在 Chrome 手动打开 chrome://extensions，找到原“Grok 本机额度同步”，点击重新加载。重载后名称变为“本机模型额度同步”。当前版本为 1.1.1，弹窗顶部会显示后台是否就绪；也可使用弹窗底部“应用本机更新”按钮自行重载。首次添加 Gemini 时增加 Gemini 站点权限；按 Chrome 提示允许后启用。已有 Grok 设置保持，Gemini 使用单独的绑定和任务状态。

## 首次安装

开启开发者模式，加载本 README 所在目录为已解压的扩展。请保持本机 http://127.0.0.1:4318 运行。

## Grok

打开扩展，点击“连接并同步 Grok”。读取官方 dashboard/usage 的周共享额度、原样重置日期与可核实的 Token 汇总。未取得字段保留未知；不导入 Credits、费用或 xAI API 余额。

## Gemini 指定账号

1. 在 Gemini 网页的 Google 账号菜单选择目标会员账号，不需要更换 Chrome 个人资料或同步账号。
2. 打开 设置 → 用量限额，刷新一次。
3. 打开同一扩展，点击“绑定当前 Gemini 用量页”。
4. 绑定完成后，可从扩展点击“同步已绑定 Gemini 账号”，或从网页工具点击同步。

Gemini 绑定账号指纹与具体用量页路径；后台不匹配时暂停更新并保留旧值，需在目标用量页明确重新绑定。邮箱只用于本机计算 SHA-256，不发送、记录或显示邮箱原文。服务端公共状态与导出不含账号指纹。

两种来源分别运行定时任务和临时标签。网页工具约每15分钟请求采集，扩展每分钟检查；通常一至两分钟内完成。Chrome 关闭、登录过期、页面结构变化时无法更新，保留上次成功数据。只关闭自己创建的临时标签，不关闭用户的原用量页。

权限仅 alarms、storage 和 grok.com、gemini.google.com、127.0.0.1:4318。Chrome 以域名授权；脚本仅在官方额度路径读取渲染 DOM。不申请 cookies、tabs、浏览历史或调试权限。不读取 Cookie、令牌、Google 账号存储、聊天、内部应用状态、网络响应或支付资料。

Gemini 只采集官方页面当前与周窗口百分比和原样重置文字；不补造年份、时区、Token 或消息次数，不导入 Gemini API、CLI 或 Antigravity 额度。价格信息不参与采集。Grok 和 Gemini 不共享绑定账号、存储命名或进行跨服务回退。

本机接口仅允许现有统一扩展的固定 Origin。停用扩展可停止全部采集；关闭网页自动刷新可停止周期任务。

2026-10-24 实测：统一扩展 1.1.1 已成功绑定目标 Gemini 网页账号，并完成本机工具发起的后台刷新；Grok 后台刷新也成功，两个来源未互相覆盖。
