# 用量数据来源

- ZenMux、GLM：服务商官方用量接口，按账号授权范围读取。
- Kimi Code：官方本机 OAuth 服务提供的订阅窗口比例，不冒充逐日 Token 历史。
- MiniMax、DeepSeek、Grok：统一浏览器扩展读取官方用量页可见数据，校验日期、分项与总量后在本机保存。
- Codex：官方本机只读额度接口，不代表所有 ChatGPT 网页模型。
- Gemini：绑定目标网页账号的用量限额页，账号变化暂停。

仅可使用服务商实际返回的计量单位，Token、请求数、百分比与余额互不折算。源码和测试不携带用户真实用量记录；运行数据在本机 `.local`。
