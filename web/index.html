安全连接本机 Loom 工作台

为保护你本机的模型 API Key 不被任意网页读取，Loom 仅接受本机桌面端或一次性终端票据登录。

方式一：通过桌面端一键打开（推荐）

macOS 用户直接打开 ~/Applications/Loom.app 或点击顶部菜单栏 ⌘ →「打开 Loom 工作台」，免命令自动安全登录。

方式二：在终端运行命令自动跳转

复制并在终端运行以下命令，浏览器会自动携带一次性票据进入工作台：

loom console
